# RC.5c — Pipeline Stages & UI Surfaces (Track B readiness trace)

**Date:** 2026-06-18 · **Branch:** `Liv` · **Method:** wired-composition trace (Athena/Orion/Reconciliator Workers + Web.UI) + adversarial refutation of every "done" claim, demanding **end-to-end evidence** (a green unit test is not readiness). Believe wiring + file:line, never comments/prose.

> **Headline:** Since the 2026-06-11 GAP-MATRIX, the codebase has moved *substantially*. The MVP-blocking ingestion + 3-process security spine (A1–A6) that 06-11 called "Planned/Partial" is now largely **built and wired** (real SIARA downloader, watch loop, 3 separately-hosted Ember-coordinated worker processes, JWT clearance hub auth, per-process audit). Multi-source fusion, SLA telemetry, unified-record persistence, and native PDF text are all **now real**. Critically, a single **max-fidelity E2E gate** proves a real case traverses all three processes with nothing stubbed *in the pipeline*. The two largest residual caveats are: (1) the cross-process transport is exercised over an **in-memory SignalR seam** in the gate (real TCP wire proven separately), and (2) the document source is the **SIARA simulator, not the live SIARA portal** (no real SIARA API exists — web-scraping the sim is the deliberate path). The two worker `/dashboard` endpoints still return hardcoded zeros.

## Biggest readiness gaps (≤6)

1. **Live SIARA portal does not exist** — the entire ingestion E2E runs against the **SIARA *simulator*** (`MaxFidelityGateE2EBase.cs:57` `localhost:5001`). Real-portal behaviour (auth, page shape, throttling) is unproven by definition. *Business/integration gap, not buildable now.*
2. **Cross-process transport proven only over an in-memory SignalR seam in the capstone gate** — production hub + JWT auth code runs, but the max-fidelity gate does not cross a real TCP boundary (`MaxFidelityGateFullPipelineE2ETests.cs:40-41`; real wire proven *separately* by HubWireTests). No single test crosses real OCR **and** real TCP simultaneously.
3. **Quality model uncalibrated against real CONDUSEF/CNBV data** — real coefficients but baked-in defaults with no `TrainedDate`/`TrainingDataSize`; never validated on the production corpus.
4. **Worker `/dashboard` endpoints return hardcoded zeros** — `Athena/OrionDashboardService` `QueueDepth:0` + uncounted documents; operational blind spot for the headless workers.
5. **Metrics are in-memory only** (`ProcessingMetricsService`) + observability not wired to a backend — no historical/aggregate metrics; resets on restart; SLA meter exported but no collector backend verified.
6. **Config still hardcodes a dev server / no Production override layer** (E2 carry-forward) + **PersonIdentityResolver has no DB persistence** — deploy-readiness tail.
